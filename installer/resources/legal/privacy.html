Windows-MCP 隐私政策

维护者及本政策联系主体：CyanQX / Windows-MCP
隐私联系邮箱：jingyanx2@gmail.com

本项目是本地桌面软件，没有项目自建的云端账号、支付或桌面内容托管服务。连接的 AI 客户端可能把工具结果发送到其模型服务；检查更新会联系 GitHub；遥测默认关闭。“本地运行”并不等于所有使用场景都没有网络传输。请先阅读下列实际数据流说明。

一、适用范围及处理主体

本政策说明本项目代码和管理器如何处理数据，以及维护者收到支持邮件或反馈时的处理方式。你选择的 AI 客户端、模型提供者、浏览器、网站和代码托管平台独立决定其服务的数据处理方式，其政策另行适用。你或所属组织自行部署、修改、运营本项目并决定数据处理目的和方式时，应依法承担相应责任；本政策不能替代你的对外告知义务。

二、数据类别、目的和处理方式

场景涉及的数据用途与去向
安装、检测、维护已安装编程端的程序位置、相关注册表安装信息、环境变量中的目录、Skill 与 MCP 配置、文件散列、安装收据、版本、备份和交易恢复记录。本地定位程序，安装或修复接入，验证连接及恢复配置。文件夹检测只读取有限层级，不运行候选程序。配置备份可能包含你原有配置中的敏感信息。
桌面和网页自动化窗口标题、应用和进程信息、控件名称与文本、可访问性树、屏幕或窗口截图、操作参数和结果；按授权调用取得的网页结构、文件内容或剪贴板内容等。在本机执行任务，并通过 MCP 返回给连接的客户端。可见画面或文本可能包含个人、业务或敏感信息。客户端可能进一步发送给其云端模型；维护者不会因此自动收到你的桌面内容。
审批、安全及审计请求标识、会话标识、工具、风险等级、操作散列、期限、决定，以及供本机操作员核对的具体参数；授权方式与签名校验信息。本地核对具体操作，防止越权与重放。审批详情采用当前 Windows 用户的 DPAPI 加密保存；持续授权在本机签名保存。审计日志记录时间、会话、工具、散列和状态，不写入工具参数、正文或异常消息。
维护日志与诊断时间、阶段、版本、错误、文件与客户端路径、连接检查结果、经过规则遮盖的诊断信息。本地排障、回滚和导出诊断。遮盖规则无法保证去除所有个人信息；导出后请自行审阅。日志和报告不自动上传。
版本检查和下载GitHub 接收连接所需的 IP 地址、请求头、请求路径和相关网络元数据；软件会读取官方发布版本、说明、资源与校验信息。管理器启动后可自动检查官方更新；只有用户启动更新流程才下载和安装。版本在本地比较。更新请求不附带桌面截图、原始配置或维护日志。网络服务有其独立日志规则。
主动联系维护者你的发件邮箱、邮件正文、主动附加的诊断材料；公开 Issues 还包括 GitHub 账号及公开反馈。答复、处理权利请求、定位问题与安全事件。仅提交必要材料，请勿发送密码、令牌、身份证件或未遮盖的业务数据。

三、可选遥测

默认配置及管理器生成的接入配置将 ANONYMIZED_TELEMETRY 设为 false。只有显式设为 true / 1 / yes / on 才启用 PostHog 遥测。启用后会发送本地随机持久标识、会话标识、工具名称、耗时、成功状态、客户端名称和版本；异常事件可能带有错误消息及上下文。当前正常调用的遥测包装不上传工具返回正文；错误消息仍可能含有路径或其他敏感内容。SDK 启用了异常自动采集，未关闭 IP 地理位置解析，不能将这类数据视为不可识别个人的完全匿名信息。

默认接收端为 https://us.i.posthog.com，属于境外服务；自定义 POSTHOG_HOST 会改变接收方。详见PostHog 隐私政策。本项目不保证第三方的实际留存期限，也不假称设定了尚未实现的服务端自动删除期限。请保持关闭，除非已了解接收方、数据类别、目的和保存安排，并具备必要的合法依据及依法需要的单独同意、个人信息保护影响评估和出境合规条件。开启环境变量本身不能替代这些法律要求。关闭变量并重启服务可停止后续遥测；已发出的数据需联系维护者和实际接收方处理。

四、处理依据与选择

由你发起的安装、维护及自动化任务，在相关主体具备合法处理依据的前提下，按任务所需最小范围处理；维护者回复你主动提出的支持请求，仅处理答复和解决问题所需的信息。依法以同意作为依据的可选处理须允许撤回，拒绝遥测不影响基本自动化功能。对依法需要单独同意的敏感信息、向其他处理者提供或出境等情形，应另行履行要求。本政策的展示、软件安装和“全自动”操作授权都不等于对全部个人信息处理的一揽子同意。

五、存储位置、期限及删除

  • 安装版通常在当前用户 .windows-mcp 目录保存服务配置、审批与信任数据，管理数据通常在 %LOCALAPPDATA%\WindowsMCP；便携版使用程序旁 data。自定义目录以“安装目录”和实际配置为准。相关客户端配置同时位于各客户端自己的用户目录。
  • 维护日志默认保留 30 天、总容量上限 50 MB，可在高级设置调整，并在日志清理或轮转时执行。服务审计按容量轮转，默认每份约 5 MB，保留当前文件及最多两份历史文件。两类日志的规则不同。
  • 配置、收据、备份、恢复记录及信任文件不会因清理维护日志而全部删除；这些内容在维护或恢复仍需使用时保留。卸载接入会优先保留个人修改和恢复资料，不能把卸载视为全部数据已删除。停止服务并处理受管接入后，你可根据实际目录删除不再需要的数据、报告和备份。删除共享数据前请确认不再需要回滚。
  • 待审批请求有明确有效期；到期后不能再批准使用，到期并不代表所有关联审计或磁盘文件立即擦除。全自动授权保留到到期或手动撤销；撤销会使该持续授权失效，不会清除历史审计记录。
  • 支持邮件和私下提供的材料原则上保留至事项办结后 90 天，届时删除或作不可识别化处理；法律要求留存或为处理正在进行的争议确需保留时，限于必要期限并限制使用。邮件服务备份的清除受服务商机制影响。公开 Issues 的保存和删除由 GitHub 及其权限机制管理，请勿公开敏感材料。

六、共享、公开及跨境

维护者不出售个人信息，不因基本功能向广告商提供桌面内容，也不自动公开你的日志。向客户提供截图、网页或文件结果属于你选择的 MCP 连接；请审查客户端及其模型供应商。GitHub 更新与反馈、默认关闭的 PostHog 遥测、你主动使用的 Gmail 邮箱渠道以及相关云端 AI 服务均可能涉及境外处理。涉及国家秘密、依法限制出境的数据或未具备合法出境条件的个人信息时，请勿向这些渠道传输。软件可在无网络情况下执行相应本地功能，是否使用云端模型取决于所选客户端；可选遥测可一直关闭。

发生依法需要转移处理责任、向其他主体提供信息、公开披露或处理敏感个人信息的情况，应按法律要求另行告知并取得所需同意；有权机关依法提出要求的，仅在核实依据及范围后处理，不作“任何情况均不提供”或“任意共享”的承诺。

七、安全保护与事件处理

项目使用用户目录隔离、适用位置的访问限制、审批参数加密、签名校验、路径范围校验及本地审计等措施降低风险。这些措施不等于对所有本地文件进行加密，也无法防御已控制当前账号的恶意软件。请保护 Windows 账号和磁盘，谨慎开放远程 MCP，避免共用长期授权。发现泄露或越权后，应停止任务、撤销授权、断开相应连接并联系维护者；维护者对其实际控制的数据采取补救措施，并在依法需要时向有关部门和受影响个人履行通知义务。

八、你的权利和联系办法

你可依法请求了解、查阅、复制、更正、补充、删除个人信息，限制或拒绝相应处理、撤回同意，要求说明处理规则，并在满足法定条件时请求转移。对完全由你控制的本地数据，可直接通过实际目录及软件设置管理；对已提交维护者的材料，请邮件说明事项和期望处理方式。维护者仅作必要的身份或请求关联验证，不要求提供无关身份证件，原则上在 15 个工作日内答复；复杂或依法不能立即完成的请求，会说明原因及后续安排，不收取不合理费用。拒绝请求时说明理由，并保留你依法投诉、举报或向有管辖权法院起诉的权利。第三方控制的数据可按其权利渠道处理，维护者在可行范围内协助。

九、未成年人及政策变更

项目不以未成年人信息采集为目的，不提供未成年人画像或广告。未成年人应在监护人指导下使用；确需处理不满 14 周岁未成年人信息时，须依法具备监护人同意及专门保护措施。维护者发现误收相关材料后，将及时采取限制处理、删除等适当措施。个人信息处理的目的、方式、类别、接收方等发生重大变化时，应在版本说明或界面提示；依法需要重新同意的，不能仅以更新政策或继续使用替代同意。

依据：《个人信息保护法》、《网络数据安全管理条例》及《未成年人网络保护条例》。
