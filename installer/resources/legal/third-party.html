三、网络服务与独立接收方

服务用途与触发数据及规则
GitHub / 发布资源 CDN读取官方版本、用户启动的下载、打开项目主页或提交 Issues；更新检查可在管理器启动后进行。连接 IP、请求头和路径等网络元数据；用户主动提交的账号资料、反馈及附件。参阅GitHub 隐私声明。公开 Issues 可被其他人看到。

你选择的 AI 客户端 / 模型服务由用户配置 MCP 连接并发起任务。可能取得截图、控件文本、网页及文件结果，并按其规则在本地或云端处理。提供者、地区和留存取决于你的选择，本项目不替第三方作训练用途或零留存承诺。
浏览器、目标网站及应用用户授权的浏览或桌面操作。登录、Cookie、播放、提交和网络记录按各应用的实际行为及政策处理。使用现有登录桌面可能以当前账号身份执行操作。
Gmail / GitHub 反馈渠道用户主动发送支持邮件或提交问题。处理主动提供的联系方式、正文和附件。可能涉及境外服务；不愿使用这些渠道时，无须提交材料即可继续相应本地功能。可先使用无敏感内容的简要询问。
